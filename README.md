# AI 工作台

本地运行的项目、对话和知识工作台。后端仅监听 `127.0.0.1`，项目数据保存在 `data/`。

## 启动

需要 Node.js 22+、pnpm 10 和 Git。Windows 终端使用系统 PowerShell，macOS/Linux 使用系统 shell。

```sh
pnpm install
pnpm dev
```

- 工作台：<http://127.0.0.1:5173>
- 后端健康检查：<http://127.0.0.1:3001/api/health>

在设置页填写 xAI API Key 后即可使用模型对话和自然语言 Agent。也可以在仓库根目录创建 `.env`，配置 `XAI_API_KEY`、`XAI_MODEL`。设置页保存的连接配置优先于环境变量，保存在本机 SQLite 中；API 和项目导出不会返回这些密钥。

## 功能

- 项目创建、编辑说明、重新绑定目录、归档、删除和 JSON 导入导出。
- 流式对话、停止、编辑重发、重新生成、分支、收藏、会话归档及 Markdown 导出。失败和中断保留原历史，成功后事务提交；同一会话不能同时生成。
- 文件编辑、项目独立草稿、刷新恢复、差异预览、确认写入和保存冲突检测。更换绑定目录前必须先处理未保存文件。
- 引用文件、文件夹、知识和规则。带空格的路径使用 `@文件 "docs/my notes.md"`；根目录使用 `@文件夹 .`。技能默认引用也会加载。
- 知识上传、网页入库、正文编辑、标签修改、删除和来源检索。
- Agent 根据任务读取目录、规则及相关文件，生成逐文件修改计划，预览并确认写入，随后运行验证命令。也支持导入 Markdown 计划。
- Git 文件选择、差异查看、提交说明草稿及提交所选文件。不会自动提交其他已暂存文件。
- 交互终端使用 node-pty 和 xterm，支持实时输出、键盘输入、调整大小、停止进程及输出引用。面板关闭后进程继续运行；服务重启后终端会话结束。
- MCP 使用官方 SDK，支持命令参数、环境变量、启停、编辑、删除、工具发现、schema 校验和手动执行。对话仅能调用逐项勾选授权的工具；更改服务器配置后需重新授权。
- 定时任务支持编辑、暂停、恢复、立即运行、重试及删除。最小间隔为 30 秒，后台每 30 秒检查，记录退出码和输出，避免同一进程内重叠执行。仅在工作台后端运行时触发，重启后过期任务合并执行一次。

## 语义检索

未配置模型时使用本地关键词检索。在设置页配置兼容 OpenAI embeddings 协议的服务地址、模型和可选密钥，例如本地服务的 `http://127.0.0.1:11434/v1`，模型需要自行安装。

环境变量配置等价：

```dotenv
EMBEDDING_BASE_URL=http://127.0.0.1:11434/v1
EMBEDDING_MODEL=bge-m3
EMBEDDING_API_KEY=
```

第一次语义检索会向配置的服务发送知识切片并建立索引；后续复用索引。文档修改或模型变更会触发重建。外部服务错误会明确返回，旧的哈希向量不会被当作语义向量使用。

## 验证

```sh
pnpm build
pnpm test
# 保持 pnpm dev 运行后，在另一个终端执行：
pnpm test:browser
```

浏览器测试默认在 Windows 使用 Edge，其他平台使用 Playwright Chromium。可设置 `PLAYWRIGHT_CHANNEL`，或运行 `pnpm exec playwright install chromium` 安装 Chromium。`WORKBENCH_URL` 可指定其他前端地址。

测试覆盖真实 SQLite 事务、Git 所选文件提交、MCP 服务进程、终端交互、模型失败与中断、草稿恢复及桌面/手机工作流。模型和 embeddings 测试使用可控响应，不代表真实服务已连通。真实服务需要用户自己的密钥和可用模型。

`data/`、`.env`、构建结果及测试截图均不提交。备份时应先停止服务，再复制 `data/`；项目导出不包含绑定的代码目录。
